# MyLinks
<img width="346" height="382" alt="image" src="https://github.com/user-attachments/assets/a9cf7d99-00a1-46ad-ac73-33e05691966c" />


자주 사용하는 웹페이지 링크를 macOS 메뉴바에서 빠르게 열 수 있는 링크 관리 앱입니다.

## 주요 기능
<img width="464" height="752" alt="스크린샷 2026-06-01 오전 1 28 06" src="https://github.com/user-attachments/assets/0c59054f-ecdc-4ba9-a281-e301417c3306" />

<img width="464" height="752" alt="image" src="https://github.com/user-attachments/assets/a770ad12-0f9a-4358-98ba-d15b5852adca" />


- 메뉴바에서 링크 목록 바로 열기
- 섹션별 링크 관리
- 링크 추가, 삭제, 순서 변경
- 웹페이지 파비콘 표시
- 링크 복사
- 로그인 시 자동 실행

## 사용 방법

1. macOS 상단 메뉴바의 MyLinks 아이콘을 클릭합니다.
2. `+` 버튼으로 섹션이나 링크를 추가합니다.
3. 링크를 클릭하면 기본 브라우저로 열립니다.
4. 링크에 마우스를 올리면 복사 버튼이 표시됩니다.
5. 링크나 섹션은 우클릭 메뉴에서 삭제할 수 있습니다.

## 설치

1. `MyLinks.app.zip` 파일의 압축을 풉니다.
2. `MyLinks.app`을 `응용 프로그램` 폴더로 옮깁니다.
3. `MyLinks.app`을 실행합니다.
